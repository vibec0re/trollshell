# trollshell v0.2.7 power profiles + battery OSD

**Status:** design
**Date:** 2026-04-26
**Author:** Claude (with annika)
**Predecessors:** `2026-04-26-osd-redesign-design.md`, `2026-04-26-v0.2.6-robustness-design.md`.

## Goal

Two independent sub-features bundled as v0.2.7. (C) Expose `power-profiles-daemon`'s active profile + selection in the Power drawer's Battery group, with an active-profile icon indicator and a checkmark on the selected nested row. (H) Surface battery state changes (plug, unplug) and threshold crossings (20% / 10% / 5%) as transient OSDs reusing the existing OSD machinery.

## Scope

### In scope

**Sub-feature C — Power profiles (`crates/hytte-services/src/power_profiles.rs` + `pages.rs::page_power`):**

- New service module subscribes to `net.hadess.PowerProfiles` (canonical) on the system bus, falls back to `org.freedesktop.UPower.PowerProfiles` (freedesktop alias) if the canonical name has no owner. Watches `Properties.PropertiesChanged` for live `ActiveProfile` updates.
- Public:

  ```rust
  #[derive(Clone, Debug, Default)]
  pub struct PowerProfilesState {
      pub active: String,         // "balanced" / "performance" / "power-saver" / ""
      pub available: Vec<String>, // empty when daemon not present
  }

  pub fn state() -> impl Signal<Item = PowerProfilesState>;
  pub fn set_active(profile: &str);
  ```

- `set_active` uses a private `CMD_CONN: Mutex<Option<Connection>>` mirroring the v0.2.6 BlueZ/wifi reconnect pattern (eviction on `zbus::Error::InputOutput`).
- Listen loop reconnects on error with 5s backoff (mirrors bluetooth/networkd).
- Service registers in `main.rs::App::with(power_profiles::service())`.
- When neither interface name is on the bus, `state()` emits an empty `PowerProfilesState` and the listen loop re-probes every 30 seconds. UI hides itself when `available.is_empty()`.

**UI for C** (`page_power`'s existing Battery group):

- A new `AdwExpanderRow` added to the Battery `AdwPreferencesGroup` after the existing Charge row.
- Title: `"Power profile"`; subtitle: humanized active profile (`"Balanced"` / `"Performance"` / `"Power saver"`).
- Prefix: `gtk::Image` with the dynamic `power-profile-{active}-symbolic` icon, rebuilt on each `state()` emission. Fallback to `system-run-symbolic` when the per-profile icon is missing.
- Nested rows: drain-and-rebuild on each `state()` emission. One `AdwActionRow` per `state.available`, title=humanized profile name, suffix=`gtk::Image` (`object-select-symbolic` checkmark) visible only when the profile is the active one. Activating a row calls `power_profiles::set_active(profile)`.
- Whole expander hides when `state.available.is_empty()`.

**Sub-feature H — Battery OSD (`trollshell/src/widgets/osd.rs`):**

- Add `Kind::Battery` variant + CSS modifier class `.battery`.
- Trigger: edge-detect `BatteryState` transitions (Charging↔Discharging) plus threshold crossings on `percentage` while discharging at 20% / 10% / 5%.
- Subscription added in `install_subscriptions()` alongside the existing volume / mic / brightness wiring. Bootstrap suppression: first emission seeds a `last_battery: RefCell<Option<Battery>>` baseline silently; subsequent emissions diff against it.
- Trigger logic factored into `detect_battery_event(prev: Option<&Battery>, curr: &Battery) -> Option<BatteryEvent>` for unit-testability.
- Renderer: `render_battery(event, &batt) -> State` produces an OSD `State` (the existing struct) keyed `Kind::Battery` with the appropriate icon/label/value/fraction.
- Reuses existing OSD machinery: `route_show` (focused-output target + first-mounted fallback), latest-wins debounce, fade+slide animations, `drawer_open` suppression on the target view.

**CSS additions in `trollshell/style.css`:**

- Reserved `.ts-osd-card.battery .ts-osd-icon { color: @accent_color; }` per-kind tint hook. No special urgency styling for Critical / Imminent (icon name carries the visual weight).
- No new color tokens.

### Out of scope

- power-profiles-daemon's `Manager.HoldProfile` API (transient app-pinned profile).
- power-profiles-daemon performance-degraded warnings (thermal throttling notifications).
- Migrating `page_power`'s legacy `panel()` layout to AdwPreferencesGroup. Separate polish milestone.
- Battery health / cycle count / design capacity rows.
- Configurable thresholds for Low / Critical / Imminent OSD (hardcoded 20% / 10% / 5%).
- "Plugged in fully" or "Fully charged" OSDs.
- New `BatteryState::Full` enum variant — UPower exposes `FullyCharged = 4` but it's not surfaced today.
- Re-firing low-battery OSDs while sustained below threshold (edge-only is the natural behavior).

### Success criteria

- `cargo clippy --workspace --all-targets -- -D warnings` clean.
- `cargo test --workspace` green; new unit tests for `detect_battery_event` (5 scenarios) + `humanize_profile_name` (2 scenarios).
- Manual:
  - **C:** Open Power drawer → "Power profile" expander appears next to Battery's Charge row. Expander's prefix icon reflects the active profile. Expand → see 3 (or 2) profile options with a checkmark on the active one. Click a different one → `powerprofilesctl get` reflects the change within ~1 second. External change (`powerprofilesctl set performance`) → UI updates within ~1 second.
  - **H:** Plug AC → "Charging — {N}%" OSD pops on focused monitor. Unplug → "On battery — {N}%" OSD. Drain to ≤20% (or simulate via `powerprofilesctl set power-saver` and aggressive drain) → "Low battery" OSD on the threshold-crossing tick. Drain past 10% → "Critical battery". Drain past 5% → "Battery very low". Bootstrap doesn't fire any OSD on shell startup. Drawer-open suppression still works when the Power drawer is open.

## §1 — Power profiles service (`crates/hytte-services/src/power_profiles.rs`)

### Public API

```rust
#[derive(Clone, Debug, Default)]
pub struct PowerProfilesState {
    pub active: String,
    pub available: Vec<String>,
}

pub struct PowerProfilesService;

impl Service for PowerProfilesService {
    type Handles = PowerProfilesHandles;

    fn start(self, rt: &tokio::runtime::Handle) -> Self::Handles {
        let handles = PowerProfilesHandles::default();
        let writer = handles.state.clone();
        rt.spawn(async move {
            loop {
                match listen(&writer).await {
                    Ok(()) => tracing::debug!("power_profiles listen ended, retrying in 5s"),
                    Err(e) => tracing::warn!(error = %e, "power_profiles error, retrying in 5s"),
                }
                tokio::time::sleep(Duration::from_secs(5)).await;
            }
        });
        handles
    }
}

#[doc(hidden)]
pub struct PowerProfilesHandles {
    pub(crate) state: Mutable<PowerProfilesState>,
}

impl Default for PowerProfilesHandles {
    fn default() -> Self {
        Self { state: Mutable::new(PowerProfilesState::default()) }
    }
}

#[must_use]
pub fn service() -> PowerProfilesService { PowerProfilesService }

pub fn state() -> impl Signal<Item = PowerProfilesState> {
    registry::with(|r| {
        r.get::<PowerProfilesHandles>()
            .expect("power_profiles::service() not registered")
            .state
            .signal_cloned()
    })
}

pub fn set_active(profile: &str) {
    let profile = profile.to_string();
    runtime::handle().spawn(async move {
        if let Err(e) = do_set_active(&profile).await {
            tracing::warn!(error = %e, profile, "power_profiles set_active failed");
        }
    });
}
```

### Listen loop with name-fallback

```rust
const CANONICAL_NAME: &str = "net.hadess.PowerProfiles";
const CANONICAL_PATH: &str = "/net/hadess/PowerProfiles";
const FREEDESKTOP_NAME: &str = "org.freedesktop.UPower.PowerProfiles";
const FREEDESKTOP_PATH: &str = "/org/freedesktop/UPower/PowerProfiles";

async fn listen(writer: &Mutable<PowerProfilesState>) -> Result<()> {
    let conn = Connection::system().await.context("connect system bus")?;
    let proxy = match build_proxy(&conn).await {
        Some(p) => p,
        None => {
            // Daemon absent. Empty state, slow retry.
            writer.set(PowerProfilesState::default());
            tokio::time::sleep(Duration::from_secs(30)).await;
            return Err(anyhow::anyhow!("power-profiles-daemon not on bus"));
        }
    };

    refresh_state(&proxy, writer).await?;
    let mut props = proxy
        .receive_signal("PropertiesChanged")
        .await
        .context("subscribe PropertiesChanged")?;
    while props.next().await.is_some() {
        if let Err(e) = refresh_state(&proxy, writer).await {
            tracing::warn!(error = %e, "power_profiles refresh failed");
        }
    }
    Ok(())
}

async fn build_proxy(conn: &Connection) -> Option<zbus::Proxy<'static>> {
    if let Ok(p) = zbus::Proxy::new(conn, CANONICAL_NAME, CANONICAL_PATH, CANONICAL_NAME).await {
        if probe(&p).await {
            return Some(p);
        }
    }
    if let Ok(p) = zbus::Proxy::new(conn, FREEDESKTOP_NAME, FREEDESKTOP_PATH, FREEDESKTOP_NAME).await {
        if probe(&p).await {
            return Some(p);
        }
    }
    None
}

async fn probe(p: &zbus::Proxy<'_>) -> bool {
    p.get_property::<String>("ActiveProfile").await.is_ok()
}

async fn refresh_state(
    proxy: &zbus::Proxy<'_>,
    writer: &Mutable<PowerProfilesState>,
) -> Result<()> {
    let active: String = proxy.get_property("ActiveProfile").await.unwrap_or_default();

    let raw: Vec<HashMap<String, OwnedValue>> = proxy
        .get_property("Profiles")
        .await
        .unwrap_or_default();
    let available: Vec<String> = raw
        .into_iter()
        .filter_map(|m| {
            m.get("Profile")
                .and_then(|v| v.try_clone().ok())
                .and_then(|v| String::try_from(v).ok())
        })
        .collect();

    writer.set(PowerProfilesState { active, available });
    Ok(())
}
```

### `do_set_active` with reconnect-on-IO

```rust
static CMD_CONN: tokio::sync::Mutex<Option<Connection>> = tokio::sync::Mutex::const_new(None);

async fn cmd_conn() -> Result<Connection> {
    let mut guard = CMD_CONN.lock().await;
    if guard.is_none() {
        let fresh = Connection::system()
            .await
            .context("open shared power_profiles command connection")?;
        *guard = Some(fresh);
    }
    Ok(guard.as_ref().expect("just stored Some").clone())
}

async fn evict_cmd_conn() {
    *CMD_CONN.lock().await = None;
}

fn is_io_error(e: &anyhow::Error) -> bool {
    e.chain().any(|cause| {
        cause
            .downcast_ref::<zbus::Error>()
            .is_some_and(|ze| matches!(ze, zbus::Error::InputOutput(_)))
    })
}

async fn do_set_active(profile: &str) -> Result<()> {
    let r = try_set_active_at(CANONICAL_NAME, CANONICAL_PATH, profile).await;
    if let Ok(()) = r { return Ok(()); }
    // Canonical interface unavailable; try the freedesktop alias.
    try_set_active_at(FREEDESKTOP_NAME, FREEDESKTOP_PATH, profile).await
}

async fn try_set_active_at(name: &str, path: &str, profile: &str) -> Result<()> {
    let conn = cmd_conn().await?;
    let r = conn
        .call_method(
            Some(name),
            path,
            Some("org.freedesktop.DBus.Properties"),
            "Set",
            &(name, "ActiveProfile", zbus::zvariant::Value::from(profile)),
        )
        .await
        .with_context(|| format!("call Properties.Set ActiveProfile on {name}"));
    if let Err(ref e) = r && is_io_error(e) {
        evict_cmd_conn().await;
    }
    r.map(|_| ())
}
```

```rust
fn build_power_profile_expander() -> adw::ExpanderRow {
    let expander = adw::ExpanderRow::builder()
        .title("Power profile")
        .build();

    // Hide entirely when daemon absent.
    bind(
        power_profiles::state().map(|s| !s.available.is_empty()),
        &expander,
        gtk::prelude::WidgetExt::set_visible,
    );

    // Subtitle = humanized active profile.
    bind(
        power_profiles::state().map(|s| humanize_profile(&s.active)),
        &expander,
        |row, t| row.set_subtitle(&t),
    );

    // Prefix: dynamic icon swapped per active profile.
    let icon = gtk::Image::new();
    bind(
        power_profiles::state().map(|s| profile_icon_name(&s.active)),
        &icon,
        |w, name| w.set_icon_name(Some(name)),
    );
    expander.add_prefix(&icon);

    // Drain-and-rebuild nested rows on each state emission.
    let rows_track: Rc<RefCell<Vec<adw::ActionRow>>> = Rc::new(RefCell::new(Vec::new()));
    let expander_for_bind = expander.clone();
    let rows_for_bind = rows_track.clone();
    bind(power_profiles::state(), &expander, move |_, state| {
        for row in rows_for_bind.borrow_mut().drain(..) {
            expander_for_bind.remove(&row);
        }
        let mut new_rows = Vec::with_capacity(state.available.len());
        for profile in &state.available {
            let row = adw::ActionRow::builder()
                .title(humanize_profile(profile))
                .activatable(true)
                .build();
            if profile == &state.active {
                let check = gtk::Image::from_icon_name("object-select-symbolic");
                check.set_valign(gtk::Align::Center);
                row.add_suffix(&check);
            }
            let profile_owned = profile.clone();
            row.connect_activated(move |_| {
                power_profiles::set_active(&profile_owned);
            });
            expander_for_bind.add_row(&row);
            new_rows.push(row);
        }
        *rows_for_bind.borrow_mut() = new_rows;
    });

    expander
}

pub(crate) fn humanize_profile(name: &str) -> String {
    match name {
        "performance" => "Performance".to_string(),
        "balanced" => "Balanced".to_string(),
        "power-saver" => "Power saver".to_string(),
        other => other.to_string(),
    }
}

fn profile_icon_name(active: &str) -> &'static str {
    match active {
        "performance" => "power-profile-performance-symbolic",
        "balanced" => "power-profile-balanced-symbolic",
        "power-saver" => "power-profile-power-saver-symbolic",
        _ => "system-run-symbolic",
    }
}
```

### Event detection

```rust
const LOW_THRESHOLD: f64 = 20.0;
const CRITICAL_THRESHOLD: f64 = 10.0;
const IMMINENT_THRESHOLD: f64 = 5.0;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
enum BatteryEvent {
    PluggedIn,
    Unplugged,
    LowBattery,
    CriticalBattery,
    ImminentShutdown,
}

fn detect_battery_event(prev: Option<&Battery>, curr: &Battery) -> Option<BatteryEvent> {
    let prev = prev?;

    if curr.state == BatteryState::Unknown || prev.state == BatteryState::Unknown {
        return None;
    }

    if prev.state == BatteryState::Discharging && curr.state == BatteryState::Charging {
        return Some(BatteryEvent::PluggedIn);
    }
    if prev.state == BatteryState::Charging && curr.state == BatteryState::Discharging {
        return Some(BatteryEvent::Unplugged);
    }

    if curr.state == BatteryState::Discharging && prev.state == BatteryState::Discharging {
        // Most-severe wins on a single tick.
        if prev.percentage > IMMINENT_THRESHOLD && curr.percentage <= IMMINENT_THRESHOLD {
            return Some(BatteryEvent::ImminentShutdown);
        }
        if prev.percentage > CRITICAL_THRESHOLD && curr.percentage <= CRITICAL_THRESHOLD {
            return Some(BatteryEvent::CriticalBattery);
        }
        if prev.percentage > LOW_THRESHOLD && curr.percentage <= LOW_THRESHOLD {
            return Some(BatteryEvent::LowBattery);
        }
    }

    None
}
```

### Renderer

```rust
fn render_battery(event: BatteryEvent, batt: &Battery) -> State {
    let (icon, label, value) = match event {
        BatteryEvent::PluggedIn => (
            "battery-charging-symbolic",
            "Charging",
            format!("{:.0}%", batt.percentage),
        ),
        BatteryEvent::Unplugged => (
            "battery-symbolic",
            "On battery",
            format!("{:.0}%", batt.percentage),
        ),
        BatteryEvent::LowBattery => (
            "battery-low-symbolic",
            "Low battery",
            format!("{:.0}%", batt.percentage),
        ),
        BatteryEvent::CriticalBattery => (
            "battery-caution-symbolic",
            "Critical battery",
            format!("{:.0}%", batt.percentage),
        ),
        BatteryEvent::ImminentShutdown => (
            "battery-caution-symbolic",
            "Battery very low",
            format!("{:.0}%", batt.percentage),
        ),
    };
    State {
        kind: Kind::Battery,
        icon,
        fraction: (batt.percentage / 100.0).clamp(0.0, 1.0),
        label,
        value,
        muted: false,
    }
}
```

### Subscription wiring (`install_subscriptions`)

A fourth `spawn_local` block alongside the existing volume / mic / brightness:

```rust
{
    let first = Cell::new(true);
    let last_battery: RefCell<Option<Battery>> = RefCell::new(None);
    glib::MainContext::default().spawn_local(
        upower::battery().for_each(move |batt: Battery| {
            if first.replace(false) {
                *last_battery.borrow_mut() = Some(batt);
                return std::future::ready(());
            }
            let prev_snapshot = last_battery.borrow().clone();
            if let Some(event) = detect_battery_event(prev_snapshot.as_ref(), &batt) {
                let state = render_battery(event, &batt);
                route_show(&state);
            }
            *last_battery.borrow_mut() = Some(batt);
            std::future::ready(())
        }),
    );
}
```

Bootstrap suppression seeds `last_battery` on the first emission so the second emission has a real baseline.

## §4 — Implementation hand-off

After approval, the writing-plans skill produces a step-by-step plan. Suggested decomposition:

1. **Service:** new `power_profiles.rs` (struct + service + listen with name-fallback + `set_active` with reconnect-on-IO + 2 unit tests for `humanize_profile`); register in `main.rs`.
2. **UI for power profiles:** `build_power_profile_expander` added to the Battery group in `page_power`; `humanize_profile` + `profile_icon_name` helpers.
3. **OSD `Kind::Battery`** + `BatteryEvent` enum + `detect_battery_event` pure helper + 7 unit tests.
4. **OSD `render_battery`** + battery subscription wired in `install_subscriptions` with bootstrap-suppression `last_battery` cell.
5. **CSS:** `.ts-osd-card.battery .ts-osd-icon { color: @accent_color; }` rule appended.
